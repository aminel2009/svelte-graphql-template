# SvelteKit 3 + GraphQL Template

Minimal, maintainable **SvelteKit 3 + Svelte 5 (Runes) + Vite 8 + Tailwind CSS v4 + TypeScript 6** boilerplate with a typed GraphQL SDK generated by [GraphQL Code Generator](https://the-guild.dev/graphql/codegen) and [`graphql-request`](https://github.com/jasonkuhrt/graphql-request).

## 1. Quick Start

Requires **Node.js ≥ 22.17** (or ≥ 24) and **pnpm**.

```bash
cp .env.example .env     # Configure PUBLIC_GRAPHQL_ENDPOINT
pnpm install
pnpm generate            # Introspects schema -> src/lib/gql/generated.ts
pnpm dev                 # Starts dev server on http://localhost:5173
```

- `PUBLIC_GRAPHQL_ENDPOINT` is declared in [`src/env.ts`](./src/env.ts) (SvelteKit 3's explicit env API) and read from `$app/env/public`.
- [`codegen.ts`](./codegen.ts) automatically loads `.env` via Node's built-in `process.loadEnvFile()` and uses `GRAPHQL_SCHEMA_URL` (if set) or falls back to `PUBLIC_GRAPHQL_ENDPOINT` (default: `http://localhost:3000/api/graphql`).

## 2. Adding & Calling a GraphQL Query

1. Create a `.gql` file anywhere under `src/`, e.g. `src/lib/gql/queries/Posts.gql`:

   ```graphql
   query Posts($limit: Int) {
   	Posts(limit: $limit) {
   		docs {
   			id
   			title
   		}
   	}
   }
   ```

2. Regenerate the typed SDK:

   ```bash
   pnpm generate        # or pnpm generate:watch
   ```

3. Call the generated operation (method name matches the GraphQL operation name):

   **Server-side (`+page.server.ts` / `+page.ts`):**

   ```ts
   import { api } from '#lib/gql/client.ts';
   import type { PageServerLoad } from './$types';

   export const load: PageServerLoad = async ({ fetch }) => {
   	// Pass SvelteKit's fetch (and optional custom headers/endpoint)
   	const data = await api(fetch).Posts({ limit: 10 });
   	return { data };
   };
   ```

   **Client-side with Stale-While-Revalidate (SWR) caching (`+page.svelte`):**

   ```svelte
   <script lang="ts">
   	import { api } from '#lib/gql/client.ts';
   	import { clearQueryCache, useQuery } from '#lib/gql/query.svelte.ts';

   	const posts = useQuery('posts', api().Posts, { ttlMs: 5 * 60_000 });
   	posts.execute({ limit: 10 });
   </script>

   {#if posts.loading}
   	<p>Loading…</p>
   {:else if posts.error}
   	<p>{posts.error.message}</p>
   {:else if posts.data}
   	<pre>{JSON.stringify(posts.data, null, 2)}</pre>
   {/if}
   ```

## 3. Development & Codegen Scripts

| Command               | Description                                                                             |
| :-------------------- | :-------------------------------------------------------------------------------------- |
| `pnpm dev`            | Starts the Vite + SvelteKit development server.                                         |
| `pnpm devsafe`        | Clears `.svelte-kit` and `node_modules/.vite` caches, then starts the dev server.       |
| `pnpm generate`       | Introspects the GraphQL schema and outputs the typed SDK to `src/lib/gql/generated.ts`. |
| `pnpm generate:watch` | Watches `src/**/*.gql` and regenerates `src/lib/gql/generated.ts` on save.              |
| `pnpm check`          | Runs `svelte-kit sync` and `svelte-check` across all Svelte 5 and TypeScript files.     |
| `pnpm check:watch`    | Runs `svelte-check` in watch mode.                                                      |
| `pnpm lint`           | Verifies formatting with Prettier and lints with ESLint.                                |
| `pnpm format`         | Formats all files with Prettier (`prettier-plugin-svelte`).                             |
| `pnpm build`          | Builds the production application.                                                      |
| `pnpm preview`        | Previews the production build locally.                                                  |

## 4. Keeping Dependencies Updated

Use the built-in maintenance scripts to update SvelteKit, Vite, and GraphQL Codegen packages cleanly:

```bash
# Update @sveltejs/*, svelte, svelte-check, and vite + sync SvelteKit types:
pnpm update:svelte

# Update @graphql-codegen/*, graphql, graphql-request, and graphql-tag:
pnpm update:graphql

# Update all dependencies in package.json to latest + sync SvelteKit types:
pnpm update:deps

# Verify types, formatting, and lint rules after updating:
pnpm check && pnpm lint
```

## 5. Project Structure

- [`src/app.css`](./src/app.css) — Tailwind CSS v4 entrypoint imported in `src/routes/+layout.svelte`.
- [`src/env.ts`](./src/env.ts) — SvelteKit 3 explicit environment schema (`PUBLIC_GRAPHQL_ENDPOINT`).
- [`codegen.ts`](./codegen.ts) — GraphQL Code Generator configuration (`typescript`, `typescript-operations`, `typescript-graphql-request`).
- [`src/lib/gql/client.ts`](./src/lib/gql/client.ts) — Exports `api(fetch?, options?)` for both client requests (`api()`) and SSR `load` functions (`api(fetch)`).
- [`src/lib/gql/query.svelte.ts`](./src/lib/gql/query.svelte.ts) — Svelte 5 runes stale-while-revalidate query helper (`useQuery` and `clearQueryCache`).
- [`src/lib/gql/queries/`](./src/lib/gql/queries/) — `.gql` operation documents.
- [`src/lib/gql/generated.ts`](./src/lib/gql/generated.ts) — Auto-generated GraphQL types and SDK (ignored by ESLint).
